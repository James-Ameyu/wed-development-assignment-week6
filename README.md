
# SpendWise - Budget Tracker

## About the Project

SpendWise is a simple budget tracking application that helps users manage their money by tracking their budgets and expenses.

The application calculates the remaining balance after expenses are deducted from the total budget.

## JavaScript Concepts Implemented

The project uses the following JavaScript concepts:

1. Variables
2. Data types
3. User input using prompt()
4. Number conversion using Number()
5. Conditional statements (if, else if, else)
6. Arithmetic calculations
7. Functions
8. DOM manipulation
9. Event listeners
10. Console output

## How Variables Are Used

Variables store important budgeting information.

- budget stores the total available budget.
- expenses stores the total money spent.
- balance stores the remaining money.

## How User Input Is Collected

The application uses JavaScript prompt() to ask users to enter their total budget and expenses.

The values are converted into numbers using Number() before calculations.

## How Calculations Are Performed

SpendWise calculates the remaining balance using:

balance = budget - expenses

For example:

Budget = 40000
Expenses = 12000
Balance = 28000

## How Functions Organize the Code

The application uses reusable functions:

- calculateBalance() calculates the remaining budget.
- displayResults() displays the budget information in the browser.

Functions make the code easier to organize, understand and maintain.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Click Calculate My Budget.
5. Enter your budget and expenses.
6. View your results on the webpage.
7. Open the browser console using F12 to see the calculation report.
